- Два варианта сообщений: для мессенджеров (WhatsApp/Telegram) и для официальной переписки (Email).
- Обязательный дисклеймер о бесплатном демо-концепте и удалении по первой просьбе.

## Инструкция по отправке
1. После деплоя сайтов (Netlify / Vercel / GitHub Pages) замените `[ССЫЛКА_НА_ДЕМО]` на реальный URL конкретного сайта.
2. Для Приоритета №1 (горячие лиды) рекомендуемый канал первого контакта — WhatsApp / Telegram по номеру телефона компании.
3. Для Приоритета №2 — акцент на проблему с текущим сайтом/доменом.
4. Для Приоритета №3 — предложение мобильного лендинга под платную рекламу.
