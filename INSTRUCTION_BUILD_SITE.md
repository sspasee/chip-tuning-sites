# Задача: собрать демо-сайт для одного бизнеса

Ты работаешь в проекте демо-лендингов для сервисов чип-тюнинга (Кемерово, Томск). Тебе назван один slug (например `kem-01`). Сделай для него готовый сайт: `content/{slug}.json` → `python template/build.py {slug}` → `sites/{slug}/`.

Делай всё сам, по порядку, без вопросов. Остановись и спроси только в случаях из раздела «Когда останавливаться».

## Правила (нарушать нельзя)
1. Не выдумывать. Каждый факт (телефон, адрес, часы, услуга, цена, число) должен быть в `data/raw/{slug}.csv`. Нет в CSV — пустая строка или пустой список, блок скроется сам.
2. Отзывы только пересказом общей темы: без имён, ников, цитат и без цифр, которых нет в `review_summary`.
3. Не писать плашку «Демо-концепт…» и noindex: их добавляет `build.py`.
4. Никаких гарантий, сроков, скидок, «с 20XX года», числа клиентов, цифр мощности и расхода топлива.
5. Не писать «официальный дилер» и подобное, кроме формата «в карточке указано …».
6. Эффекты из отзывов (прирост мощности, расход, динамика) только как «клиенты отмечают», не как обещание сервиса.
7. Удаление катализатора, сажевого фильтра, EGR, прошивка Евро-2: только нейтрально, если услуга есть в CSV. Например: «выполняется по запросу владельца автомобиля». Без обещаний легальности и без советов, как обойти проверки.
8. Единичные негативные случаи из `review_summary` на сайт не выносить, но и не опровергать.
9. Не править `template/`, `data/`, `PLAN.md`, чужие файлы. Не запускать `build.py` без аргумента (он соберёт и `sample.json`).

## Шаги
1. Прочитай: `data/raw/{slug}.csv` (разделитель `;`, 18 полей), `content/sample.json` (структура), `template/index.html` (какие блоки есть).
2. Создай `content/{slug}.json` ровно по структуре `sample.json`. Поля с `_` в начале не копируй.
3. Заполни поля:
   - `name`, `city`, `category`, `phone`, `address`, `hours`, `rating`, `reviews_count`, `source_url` берутся из CSV. Телефон можно оформить пробелами (`+7 906 983-95-30`), цифры не менять. Если телефонов два, пиши оба через запятую.
   - `headline`: одна фраза, чем занимается сервис, только из `services`.
   - `subheadline`: формат работы (запись, часы), только из CSV.
   - `meta_description`: до 150 символов: название, главная услуга, город.
   - `about`: 2–4 предложения только по данным. Мало данных — пиши короче или оставь пустым.
   - `services`: объекты `{title, text, price}`. `title` берётся из `services` CSV. `price` берётся из `prices` CSV для услуги с тем же названием и в той же формулировке («от 3 000 ₽», «бесплатно»). Нет цены — `""`. `text` одно короткое предложение только по данным, иначе `""`.
   - `reviews_summary`: пересказ `review_summary` 2–3 предложениями без негатива и цитат. Пусто, если в CSV пусто.
   - `prices_note`: пусто, если нечего добавить из CSV.
4. Запусти `python template/build.py {slug}`. Должно напечатать `OK {slug}`.
5. Самопроверка по готовому `sites/{slug}/index.html`:
   - есть плашка «Демо-концепт, не официальный сайт, удалим по первой просьбе» и `noindex`;
   - ссылка `tel:` совпадает с телефоном из CSV;
   - в тексте нет ни одной цифры, цены или услуги, которых нет в CSV;
   - нет имён людей, ников, цитат;
   - нет внешних скриптов и фреймворков.
   Нашёл ошибку — исправь `content/{slug}.json` и пересобери.
6. Отчёт не длиннее 3 строк: что сделано, что оставил пустым и почему, что сомнительно.

## Известные особенности данных
- **Цены-заглушки** («1 ₽», «0 ₽») не цена: в `price` не переносить (в tom-02 это «Тюнинг и ремонт выхлопных систем» и «Детали для выхлопных систем»).
- **Имена владельцев и ИП, личные ники (@…) из `notes`** на сайт не переносить. Контакты соцсетей из `notes` не использовать, только телефон и адрес из своих полей.
- **Если название услуги в `prices` не совпадает с названием в `services`** (разный порядок слов, «лямбда-зонд» и «лямбда-зонда»), сопоставляй по смыслу только при очевидном совпадении. При сомнении оставь цену пустой и скажи об этом в отчёте.
- **`hours`** бывает без времени («по предварительной записи»): пиши как есть, время не придумывай.
- **kem-10**: адрес в посёлке Металлплощадка (Кемеровский округ), город в тексте пиши как в CSV, не «уточняй».

## Когда останавливаться и спрашивать
- Нет `data/raw/{slug}.csv` или в строке данных не 18 полей.
- slug из списка не готов: **kem-03** (статус сайта на перепроверке), **kem-09** (это детейлинг-центр, не чип-тюнинг, ждёт решения) и все slug, для которых ещё нет CSV.
- Не уверен, можно ли написать факт. В таком случае не пиши его и сообщи в отчёте.
