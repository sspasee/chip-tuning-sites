## 2. Детальный разбор критериев проверки

- На всех 21 страницах присутствует элемент `<div class="demo" role="note">` со строгим неизменным текстом:

### 2.2. Тройной noindex (Правило проекта 3)
- **Уровень 1 (HTML Head):** `<meta name="robots" content="noindex, nofollow, noarchive">` присутствует в `<head>` всех 21 сайтов.
- **Уровень 2 (robots.txt):** файл `sites/{slug}/robots.txt` присутствует во всех папках с содержимым:
  ```txt
  User-agent: *
  Disallow: /
  ```
- **Уровень 3 (_headers):** файл `sites/{slug}/_headers` присутствует во всех папках с директивой:
  ```txt
  /*
    X-Robots-Tag: noindex, nofollow, noarchive
  ```

### 2.3. Ссылки tel: в кнопке-пилюле таблички (Правило проекта 6)
