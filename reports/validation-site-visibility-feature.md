## 2. Детальные свидетельства и результаты проверки

### 2.1. Шаблон страницы-заглушки (`template/deactivated.html`)

1. **Соблюдение Правила №3:**
   - В верхней части страницы размещена плашка:
     ```html
     <div class="disclaimer-bar">
       Демо-концепт, не официальный сайт, удалим по первой просьбе
     </div>
     ```
     Текст совпадает символ-в-символ с обязательным требованием Правила №3 проекта.
   - В теге `<head>` присутствует:
     ```html
     <meta name="robots" content="noindex, nofollow, noarchive">
     ```
   - Дополнительно в процедуре деактивации сайта (`build()` в `template/build.py`, строки 679–680) создаются:
     - `sites/{slug}/robots.txt`:
       ```
       User-agent: *
       Disallow: /
       ```
     - `sites/{slug}/_headers`:
       ```
       /*
         X-Robots-Tag: noindex, nofollow, noarchive
       ```

2. **Соблюдение Правила №1 и приватность данных:**
   - В разметке отсутствуют вымышленные данные: никаких домыслов о ценах, выдуманных гарантиях или фальшивых отзывах.
   - В шаблоне предусмотрены условные блоки `{{#if name}}`, `{{#if city}}`, `{{#if reason}}`, `{{#if updated_at}}`. Если поле пустое, блок в разметку не попадает (протестировано через парсер шаблона).
   - Все контактные данные бизнеса (телефон, адрес, график работы, ссылки на мессенджеры, карта) и фотографии полностью исключены из страницы-заглушки.
   - Механизм деактивации в `template/build.py` при `is_hidden = True` выполняет `shutil.rmtree(out, ignore_errors=True)` и воссоздаёт чистую папку `sites/{slug}/`, в которую записываются только `index.html`, `robots.txt` и `_headers`. Папка `img/` со всеми фото сервиса физически удаляется из опубликованной папки сайта.

3. **Мобильная адаптивность (360–390 px):**
   - Наличие мета-тега: `<meta name="viewport" content="width=device-width, initial-scale=1">`.
   - Глобальный сброс: `* { box-sizing: border-box; margin: 0; padding: 0; }`, `body { overflow-x: hidden; }`.
   - Карточка центрирована во flex-контейнере `.main-wrap` с боковыми отступами `16px`. Ширина карточки `.card` ограничена `max-width: 560px; width: 100%;`. На экранах 360–390 px ширина карточки составляет от 328 до 358 px.
   - В медиазапросе `@media (max-width: 480px)` внутренние отступы карточки уменьшены с `36px 28px` до `26px 18px`, а размер заголовка `h1` скорректирован до `19px`.
   - Кнопка возврата в каталог `.btn-catalog` занимает 100% доступной ширины и имеет `min-height: 44px`, что гарантирует удобство нажатия на смартфонах.
   - Горизонтальная прокрутка полностью отсутствует (overflow = 0 px).
   - *Замечание по стилям:* Для шрифтов и отступов использована комбинация `max-width` и `@media (max-width: 480px)` вместо функции CSS `clamp()`. Это обеспечивает требуемый перенос и читаемость на 360–390 px.

### 2.2. Сводный каталог сайтов (`sites/index.html`)

1. **Защита от индексации:**
   - `sites/index.html` (строка 6): `<meta name="robots" content="noindex, nofollow, noarchive">` присутствует.
   - `sites/robots.txt`: файл существует в корне директории `sites/` и содержит директиву полного запрета индексации (`Disallow: /`).
   - `sites/_headers`: файл существует в корне `sites/` и содержит заголовок безопасности `X-Robots-Tag: noindex, nofollow, noarchive` для хостинга Netlify/Cloudflare Pages.
   - В начале каталога размещён предупреждающий баннер: «⚠️ Демо-концепт для демонстрации возможностей. Не официальный каталог. Все данные взяты из открытых источников 2ГИС. Индексация запрещена (noindex).».

2. **Работа фильтров и интерактивных табов:**
   - В текущем состоянии каталога отображаются кнопки табов:
     - «Все активные (21)» (`data-filter="all"`, класс `active`);
     - «Кемерово (15)» (`data-filter="kem"`);
     - «Томск (6)» (`data-filter="tom"`).
   - В коде генератора каталога (`template/build.py`, строки 990–992) вкладка «Скрытые» формируется по условию `if total_hidden > 0`:
     ```python
     if total_hidden > 0:
         tabs_html += f'\n            <button type="button" class="tab-btn tab-btn-hidden" data-filter="hidden">Скрытые ({total_hidden})</button>'
     ```
     Поскольку на данный момент все 21 сайтов активны (`total_hidden = 0`), вкладка не захламляет интерфейс пустым состоянием, что является логичным поведением.
   - Функция JavaScript `applyFilter(filter)` в `sites/index.html` (строки 724–760) содержит полную поддержку фильтра `'hidden'`:
     - Скрывает активные карточки и показывает только карточки с `data-status="hidden"`;
     - Динамически обновляет счётчики видимых объектов в заголовках секций (`#count-kem`, `#count-tom`);
     - Скрывает секцию города полностью, если в ней нет видимых объектов.
   - При деактивации сайта через CLI карточка скрытого сервиса выводится с серой плашкой «Отключён по запросу», надписью «Контакты скрыты по запросу», блоком причины отключения и кнопкой перехода на заглушку.

3. **Соблюдение Правила №4 (чистый стек):**
   - Полное отсутствие внешних CSS-фреймворков (нет Tailwind, Bootstrap и т.д.).
   - Полное отсутствие сторонних JS-библиотек (нет jQuery, React, Vue, Lodash).
   - Код скрипта фильтрации занимает ровно 55 строк чистого Vanilla JS с использованием стандартного DOM API.

## 3. Замечания и рекомендации (не блокирующие)

1. **Код скрипта `template/build.py`:**
   - Функции `load_statuses()` и `save_statuses()` определены в коде трижды подряд (строки 588–605, 607–624, 626–643). Это не вызывает ошибок выполнения (Python перезаписывает предыдущее определение), но является избыточным дублированием. Рекомендуется при ближайшем рефакторинге удалить 2 лишние копии.
2. **Таб «Скрытые» в каталоге:**
   - Если координатор или пользователь предпочтут видеть таб «Скрытые (0)» даже при отсутствии отключённых сайтов, в `template/build.py` достаточно убрать условие `if total_hidden > 0:`. В текущей реализации таб появляется автоматически только при наличии скрытых объектов, что также корректно с точки зрения UX.
3. **Использование `clamp()` в стилях заглушки:**
   - Для типографики в `template/deactivated.html` используется медиазапрос `@media (max-width: 480px)` (`font-size: 19px` против `22px`). При необходимости плавного масштабирования можно перевести заголовок на `font-size: clamp(18px, 4.5vw, 22px)`.
